# Pilot dashboard

Owners see **Pilot** in the menu. It answers one question: is it safe to keep running?

| Card                       | Healthy looks like                                                                                                                                                  |
| -------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Invariant check**        | _All invariants hold_: cabins, holds and bookings add up everywhere                                                                                                 |
| **Oversells**              | _No oversells_. A cabin taken out in an emergency while booked is listed separately: sales there are already stopped                                                |
| **Request response times** | Requests received and answered in the last 30 days, how many are waiting or timed out, and how fast you answer (median, and the time within which 90% are answered) |
| **Open exceptions**        | Few, and not old                                                                                                                                                    |
| **Bookings by channel**    | Bookings, confirmed, cancelled and open requests per channel in the last 30 days                                                                                    |

If the invariant check ever shows a problem, sales have already stopped where it occurred. Contact the Riverdesk team.
