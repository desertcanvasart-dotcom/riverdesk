# المصادقة

تُنشئ شركة الرحلات لك **عميل API** في ريفرديسك وترسل إليك:

- **معرّف العميل** (`vsc_…`)، وهو ليس سرًّا؛
- **سر العميل** (`vss_…`)، ويظهر لها مرة واحدة فقط. احتفظ به على خادمك فقط.

## الحصول على token

```bash
curl -s -X POST "$API/oauth/token" \
  -u "$CLIENT_ID:$CLIENT_SECRET" \
  -d grant_type=client_credentials
```

```json
{ "access_token": "eyJ…", "token_type": "Bearer", "expires_in": 900 }
```

أرسله مع كل استدعاء بالشكل `Authorization: Bearer <token>`. صلاحية الـ token ١٥ دقيقة. وعندما يُعيد استدعاءٌ ما `401 UNAUTHENTICATED`، احصل على token جديد وأعد المحاولة.

يمكن أيضًا إرسال معرّف العميل وسره كحقول نموذج (`client_id`، `client_secret`) بدلًا من Basic auth.

## تدوير السر

يمكن أن يكون للعميل سرّان نشطان في الوقت نفسه، فتستطيع تغيير الأسرار دون توقف الخدمة:

1. اطلب من الشركة **سرًّا ثانيًا**.
2. انشره وتحقق من أن الـ tokens تعمل.
3. اطلب منها **إلغاء** السر القديم.

## حد معدل الطلبات

يحق لكل عميل إجراء ٦٠٠ طلب في الدقيقة، ما لم تحدد الشركة حدًّا آخر. وعند تجاوزه تتلقى `429 RATE_LIMITED` مع header باسم `Retry-After` بالثواني.
