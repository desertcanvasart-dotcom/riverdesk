# المصادقة

تنشئ شركة المراكب النيلية عميلًا لواجهتك، وتزوّدك بما يلي:

- **معرّف العميل:** يبدأ عادةً بـ`vsc_`، ولا يُعدّ معلومة سرية.
- **المفتاح السري للعميل:** يبدأ عادةً بـ`vss_`، ويظهر للشركة مرة واحدة فقط. احتفظ به على خادمك فقط.

## الحصول على رمز وصول

```bash
curl -s -X POST "$API/oauth/token" \
  -u "$CLIENT_ID:$CLIENT_SECRET" \
  -d grant_type=client_credentials
```

مثال للاستجابة:

```json
{
  "access_token": "eyJ…",
  "token_type": "Bearer",
  "expires_in": 900
}
```

أرسل رمز الوصول مع كل طلب:

```http
Authorization: Bearer <token>
```

تبلغ صلاحية الرمز ١٥ دقيقة. وإذا أعاد أحد الطلبات `401 UNAUTHENTICATED`، فاحصل على رمز جديد ثم أعد المحاولة.

يمكن أيضًا إرسال معرّف العميل والمفتاح السري في حقلي النموذج `client_id` و`client_secret` بدلًا من استخدام مصادقة HTTP Basic.

## استبدال المفتاح السري دون تعطيل الخدمة

يمكن أن يكون للعميل مفتاحان سريان نشطان في الوقت نفسه.

لاستبدال المفتاح:

1. اطلب من الشركة إنشاء مفتاح سري ثانٍ.
2. حدّث إعدادات خادمك لاستخدامه، وتحقّق من نجاح الحصول على رموز الوصول.
3. اطلب من الشركة إلغاء صلاحية المفتاح القديم.

## حد معدل الطلبات

الحد الافتراضي لكل عميل هو ٦٠٠ طلب في الدقيقة، ما لم تحدّد الشركة حدًا مختلفًا.

عند تجاوز الحد، تُعاد الاستجابة `429 RATE_LIMITED`، مع ترويسة `Retry-After` التي تحدّد مدة الانتظار بالثواني.
