# الحجوزات المؤقتة والحجوزات

## الحجز المؤقت (hold)

```bash
curl -s -X POST "$API/v1/holds" -H "$H" -H "Idempotency-Key: $(uuidgen)" \
  -H 'Content-Type: application/json' \
  -d '{ "quote_id": "'$QUOTE'", "kind": "checkout" }'
```

| `kind`     | استخدمه عندما                      | المدة (الافتراضية في العقد) |
| ---------- | ---------------------------------- | --------------------------- |
| `checkout` | يدفع عميلك على موقعك الآن          | ٣٠ دقيقة                    |
| `option`   | خيار مبدئي لوكيل ريثما يقرر العميل | ٧٢ ساعة                     |

تبقى الكبائن محجوزة على كل مرحلة حتى `expires_at`. وإذا لم يكن هناك مكان، يفشل الاستدعاء بالخطأ `NOT_AVAILABLE`. وعندما ينبغي إنهاء حجز مؤقت مهجور مبكرًا، حرِّره: `DELETE /v1/holds/{id}`. أما الحجوزات المؤقتة المنتهية فتتحرر تلقائيًا، وتتلقى `hold.expired`.

## التأكيد

```bash
curl -s -X POST "$API/v1/holds/$HOLD/confirm" -H "$H" -H "Idempotency-Key: $(uuidgen)" \
  -H 'Content-Type: application/json' \
  -d '{
    "channel_ref": "NC-50211",
    "guests": [
      { "cabin": 0, "first_name": "Emma", "last_name": "Clarke", "lead": true, "nationality": "GB" }
    ]
  }'
```

- `channel_ref` هو رقم الحجز **لديك**. وهو فريد لكل قناة وبشكل دائم: التأكيد مرة أخرى بالقيمة نفسها لـ `channel_ref` يُعيد الحجز الموجود. هذه شبكة الأمان لديك بعد أي انقطاع طويل.
- ضيف واحد بالضبط هو **الضيف الرئيسي** (lead). و`cabin` هو ترتيب الكابينة في عرض السعر، بدءًا من ٠.
- يُقبَل `passport_number` و`date_of_birth`، ويُشفَّران، ولا يُعادان أبدًا.

النتيجة هي **الحجز**، مع رقمه المرجعي (مثل `VS-26-00611`) وحالته:

| الحالة      | المعنى                                                                       |
| ----------- | ---------------------------------------------------------------------------- |
| `confirmed` | تم                                                                           |
| `requested` | عقدك يعمل بالائتمان وقد تجاوزت حدك (`reason: "credit_limit"`): القرار للشركة |

## قراءة حجز

```bash
curl -si "$API/v1/bookings/$REF" -H "$H"
```

تحتوي الاستجابة على الإبحار ومراحله، والكبائن وأسماء الضيوف، والإجماليات، والدفعات المستحقة، و**المراجعة** (revision) الحالية. والمراجعة هي أيضًا قيمة header المسمى `ETag`، وتُرسلها عندما [تعدّل الحجز](/docs/channel-api/changes-and-cancellations). لا يمكنك قراءة إلا حجوزاتك: حجز قناة أخرى يُعيد `404`.
