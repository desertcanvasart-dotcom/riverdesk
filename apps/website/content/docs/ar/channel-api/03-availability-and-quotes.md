# الإمكانية وعروض الأسعار

## المراكب والفئات المسموح ببيعها

```bash
curl -s "$API/v1/vessels" \
  -H "Authorization: Bearer $TOKEN"
```

يعيد الطلب المراكب المشمولة في عقدك، مع فئات الكبائن المسموح ببيعها لكل مركب.

## مواعيد الإبحار

```bash
curl -s \
  "$API/v1/sailings?vessel=$VESSEL&from=2026-11-01&to=2026-11-30" \
  -H "$H"
```

تعرض الاستجابة مواعيد الإبحار المفتوحة التي يقع تاريخ صعودها ضمن الفترة المطلوبة، بحد أقصى ٤٠٠ يوم.

وتشمل رمز برنامج الرحلة، وموانئ الصعود والنزول وتواريخهما، وعدد الليالي.

استخدم معامل `nights` لتصفية النتائج بحسب المدة، إذا كنت تبيع برامج بعدد ليالٍ محدّد.

## الكبائن المتاحة

```bash
curl -s \
  "$API/v1/availability?vessel=$VESSEL&from=2026-11-02&to=2026-11-30" \
  -H "$H"
```

يمكن الاستعلام عن فترة لا تتجاوز ١٢٠ يومًا في الطلب الواحد.

تعرض الاستجابة البيانات التالية لكل موعد إبحار وفئة مشمولة بالعقد:

| الحقل        | المعنى                                                                                                                          |
| ------------ | ------------------------------------------------------------------------------------------------------------------------------- |
| `status`     | القيمة `instant` تسمح بالحجز المؤقت والتأكيد، و`on_request` تعني ضرورة إرسال طلب للموافقة، و`sold_out` تعني عدم توافر أماكن.    |
| `free`       | عدد الكبائن الذي يمكنك حجزه على جميع مراحل الرحلة، وفق حصتك والمخزون المشترك، مع تطبيق حد الإمكانية المعروض إذا نصّ عليه العقد. |
| `from_price` | أقل سعر للفرد في الإشغال المزدوج، من بين خطط الأسعار المسموح لقناتك ببيعها.                                                     |

استجابة الإمكانية هي المرجع المعتمد لعدد الكبائن المتاحة. أعد الاستعلام عند استلام الحدث `availability.changed`.

## إنشاء عرض سعر

يحسب عرض السعر تكلفة موعد إبحار واختيار كبائن وضيوف محدّد، وفق شروط عقدك.

```bash
curl -s -X POST "$API/v1/quotes" \
  -H "$H" \
  -H "Idempotency-Key: $(uuidgen)" \
  -H 'Content-Type: application/json' \
  -d '{
    "sailing_id": "'$SAILING'",
    "market": "international",
    "cabins": [
      {
        "category_id": "'$STD'",
        "adults": 2,
        "child_ages": [7]
      }
    ]
  }'
```

تتضمن الاستجابة:

- الإجمالي.
- تفاصيل البنود: البالغون، والأطفال بحسب الشرائح العمرية، والرسوم الإضافية، ونسبة الزيادة أو العمولة.
- سياسات الإلغاء والدفع التي ستنطبق على الحجز.

أدخل أعمار الأطفال **في يوم الصعود**.

## أخطاء تسعير الاختيار

| الرمز                | المعنى                                     |
| -------------------- | ------------------------------------------ |
| `INVALID_OCCUPANCY`  | يتجاوز عدد الضيوف السعة المسموح بها للفئة. |
| `NO_RATE_FOR_SEASON` | لا يتوفر سعر للتاريخ المطلوب.              |
| `CONTRACT_FORBIDS`   | الاختيار غير مسموح به في عقدك.             |
| `SAILING_CLOSED`     | موعد الإبحار مغلق للبيع.                   |

تمتد صلاحية عرض السعر بما يغطي أطول مدة حجز مؤقت يمكن إنشاؤه استنادًا إليه.
