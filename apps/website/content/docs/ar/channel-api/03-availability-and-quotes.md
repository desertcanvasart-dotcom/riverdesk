# الإتاحة وعروض الأسعار

## ما يحق لك بيعه

```bash
curl -s "$API/v1/vessels" -H "Authorization: Bearer $TOKEN"
```

يُعيد هذا الاستدعاء البواخر الواردة في عقدك، ولكل منها فئات الكبائن التي يحق لك بيعها.

## الإبحارات

```bash
curl -s "$API/v1/sailings?vessel=$VESSEL&from=2026-11-01&to=2026-11-30" -H "$H"
```

يُعيد الإبحارات المفتوحة التي يبدأ صعودها ضمن النطاق المحدد (بحد أقصى ٤٠٠ يوم)، مع رمز خط السير، وموانئ الصعود والنزول وتواريخهما، وعدد الليالي. صفِّ النتائج بـ `nights` إذا كنت تبيع مدة واحدة فقط.

## الإتاحة

```bash
curl -s "$API/v1/availability?vessel=$VESSEL&from=2026-11-02&to=2026-11-30" -H "$H"
```

لكل إبحار ولكل فئة متعاقد عليها (بحد أقصى ١٢٠ يومًا في كل استدعاء):

| الحقل        | المعنى                                                                                                                     |
| ------------ | -------------------------------------------------------------------------------------------------------------------------- |
| `status`     | `instant`: يمكنك الحجز المؤقت والتأكيد؛ `on_request`: عقدك يشترط السؤال أولًا؛ `sold_out`                                  |
| `free`       | الكبائن التي يمكنك أخذها على كل مرحلة من مراحل الرحلة: تخصيصك مضافًا إليه المخزون المشترك، مع سقف إذا كان في عقدك سقف ظاهر |
| `from_price` | للفرد في الإشغال المزدوج، على أرخص خطة أسعار يحق لك بيعها                                                                  |

الإتاحة هي دائمًا المرجع الموثوق. أعد قراءتها عندما تتلقى `availability.changed`.

## عروض الأسعار

يُسعِّر عرض السعر إبحارًا واحدًا لكبائن وضيوف محددين وفق عقدك:

```bash
curl -s -X POST "$API/v1/quotes" -H "$H" -H "Idempotency-Key: $(uuidgen)" \
  -H 'Content-Type: application/json' \
  -d '{
    "sailing_id": "'$SAILING'",
    "market": "international",
    "cabins": [{ "category_id": "'$STD'", "adults": 2, "child_ages": [7] }]
  }'
```

تحتوي الاستجابة على **الإجمالي**، وكل **بند** (البالغون، والأطفال حسب الفئة العمرية، والمبالغ الإضافية، وهامش ربحك أو عمولتك)، و**السياسات** التي ستُطبَّق (الإلغاء، والدفع). أعمار الأطفال هي أعمارهم **في تاريخ الصعود**.

قد يفشل عرض السعر بأحد الأخطاء التالية:

- `INVALID_OCCUPANCY`: عدد الضيوف أكبر مما تسمح به الفئة؛
- `NO_RATE_FOR_SEASON`: لا يوجد سعر محدد لذلك التاريخ؛
- `CONTRACT_FORBIDS`: غير مشمول في عقدك؛
- `SAILING_CLOSED`: الإبحار مغلق.

تبقى صلاحية عرض السعر بقدر أطول حجز مؤقت يمكن أن يستند إليه.
