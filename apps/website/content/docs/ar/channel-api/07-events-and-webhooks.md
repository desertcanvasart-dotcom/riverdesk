# الأحداث وإشعاراتها التلقائية — Webhooks

كل تغيير يخص قناتك يُسجَّل بوصفه حدثًا. يرسل ريفرديسك الأحداث إلى عنوان استقبال الإشعارات لديك، ويمكنك قراءتها أيضًا من سجل الأحداث.

## استقبال الإشعارات والتحقّق منها

تسجّل شركة المراكب النيلية عنوان الاستقبال، وتزوّدك بالمفتاح السري المستخدم في التوقيع.

يصل كل حدث في طلب `POST` يتضمن:

```http
X-VS-Event-Id: <uuid>
X-VS-Signature: t=<unix seconds>,v1=<hex HMAC-SHA256(secret, "<t>.<raw body>")>
```

أعد استجابة ناجحة من فئة `2xx` خلال ١٠ ثوانٍ.

إذا فشل التسليم، يعيد ريفرديسك المحاولة بفترات انتظار متزايدة لمدة ٢٤ ساعة. ويمكن للشركة مراجعة محاولات التسليم وإعادة إرسال الإشعارات.

تحقّق من توقيع كل إشعار قبل الاعتماد عليه، باستخدام نص جسم الطلب الأصلي:

```typescript
import { createHmac, timingSafeEqual } from 'node:crypto';

export function verify(
  secret: string,
  rawBody: string,
  header: string,
  now = Math.floor(Date.now() / 1000),
) {
  const parts = Object.fromEntries(header.split(',').map((p) => p.split('=', 2)));

  const t = Number(parts.t);

  // ارفض الطابع الزمني إذا تجاوز الفرق خمس دقائق.
  if (!Number.isInteger(t) || Math.abs(now - t) > 300) {
    return false;
  }

  const expected = createHmac('sha256', secret).update(`${t}.${rawBody}`).digest();

  const given = Buffer.from(parts.v1 ?? '', 'hex');

  return given.length === expected.length && timingSafeEqual(given, expected);
}
```

## ترتيب الأحداث والتعامل مع التكرار

تُسلَّم أحداث المورد الواحد، مثل حجز أو حجز مؤقت، بالترتيب. وينتظر الحدث اللاحق تسليم الحدث السابق.

يعتمد التسليم على ضمان الوصول مرة واحدة على الأقل، لذلك قد تستقبل الحدث نفسه أكثر من مرة.

احتفظ بأعلى قيمة `resource_version` طُبّقت لكل `resource_id`، وتجاهل أي حدث لا يحمل إصدارًا أحدث.

## أنواع الأحداث

| الحدث                                                       | المعنى والإجراء                                                                                  |
| ----------------------------------------------------------- | ------------------------------------------------------------------------------------------------ |
| `availability.changed`                                      | تغيّرت الإمكانية على مرحلة وفئة. أعد الاستعلام عن التواريخ المتأثرة.                             |
| `sailing.changed`                                           | أُلغيت رحلة، أو تغيّر موعدها أو أحد موانئها.                                                     |
| `rate.changed`                                              | تغيّرت أسعار خطة تبيعها قناتك. وتحتفظ عروض الأسعار والحجوزات القائمة بأسعارها.                   |
| `hold.expired`                                              | انتهت صلاحية أحد الحجوزات المؤقتة لقناتك.                                                        |
| `booking.confirmed`، `booking.amended`، `booking.cancelled` | تغيّرت حالة الحجز أو بياناته. اقرأ الحجز للحصول على التفاصيل الحالية.                            |
| `booking.paid_unavailable`                                  | وصلت دفعة بعد انتهاء الحجز المؤقت ونفاد الكبائن. تعالج الشركة الحالة باقتراح بديل أو ردّ المبلغ. |
| `request.decided`                                           | صدر قرار بشأن طلب الحجز.                                                                         |
| `offer.created`                                             | أُنشئ عرض بديل لطلبك.                                                                            |
| `payment.recorded`، `payment.overdue`                       | سُجّلت دفعة أو تأخّر سداد مبلغ مستحق على الحجز.                                                  |

للتفاصيل المتعلقة بالطلبات، راجع [الطلبات والعروض البديلة](/docs/channel-api/requests-and-offers).

## استعادة الأحداث الفائتة

بعد انقطاع الخدمة لديك، استأنف قراءة السجل من آخر مؤشر محفوظ.

لقراءة الصفحة الأولى:

```bash
curl -s "$API/v1/events?limit=500" -H "$H"
```

ولمتابعة القراءة:

```bash
curl -s \
  "$API/v1/events?after=$NEXT_CURSOR&limit=500" \
  -H "$H"
```

احفظ `next_cursor` بعد كل صفحة. وعندما تُعاد صفحة فارغة، تكون قد وصلت إلى أحدث الأحداث المتاحة.

لا يعرض السجل الحدث إلا بعد اكتمال اعتماده في قاعدة البيانات، ويرتّب الأحداث بحسب الاعتماد، حتى لا يتجاوز المؤشر حدثًا لم يكتمل بعد.
