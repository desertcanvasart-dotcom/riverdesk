# قنوات البيع

قناة البيع هي أي جهة تبيع كبائنك: مكتبك، أو شركة، أو منصة إلكترونية مثل nilecrz.

لكل قناة عقد مستقل لكل مركب. ولشرح المفهوم، راجع [قنوات البيع والعقود](/docs/concepts/channels-and-contracts).

![قنوات البيع](/screens/{locale}/desktop-channels.jpg 'شاشة «قنوات البيع»، بالعقود وحصص الكبائن وبيانات الربط لكل قناة.')

## العقود

يعرض كل عقد:

- **طريقة إتاحة الكبائن:** مخزون مشترك، أو حصة مخصّصة، أو حجز عند الطلب.
- **طريقة الدفع:** تحصيل عبر قناة البيع، أو دفع مسبق لك، أو بيع بالآجل.
- **التسعير:** السعر الأساسي كما هو، أو نسبة زيادة، أو عمولة.
- **مدد الحجوزات المؤقتة:** مهلة إتمام الدفع ومهلة الحجز المؤقت للشركة.
- **مهلة الرد:** للعقود التي تعمل بنظام الحجز عند الطلب.

يتيح «إيقاف البيع» تعليق الحجوزات لقناة واحدة دون التأثير على القنوات الأخرى، ويُعيد «استئناف البيع» إتاحتها.

يختص المالكون بإضافة القنوات والعقود.

## حصص الكبائن المخصّصة للشركات

تحفظ الحصة عددًا من الكبائن لشركة بعينها على رحلات محدّدة.

يمكن للمالكين وموظفي الحجوزات اختيار «تخصيص جديد»، وتحديد:

- الفترة الزمنية.
- عدد الكبائن لكل فئة.
- عدد الأيام قبل الرحلة التي تُعاد عندها الكبائن غير المستخدمة إلى البيع العام.

تُعاد السعة غير المستخدمة تلقائيًا في الموعد المحدّد.

## عملاء واجهة برمجة التطبيقات

تستخدم المنصة معرّف عميل ومفتاحًا سريًا للمصادقة مع ريفرديسك.

- اختر «عميل جديد» لإنشاء بيانات الربط.
- يظهر المفتاح السري مرة واحدة فقط، مع خيار نسخه. سلّمه إلى المنصة عبر وسيلة آمنة.
- لاستبداله دون تعطيل الربط، أضف مفتاحًا ثانيًا، وانتظر انتقال المنصة إليه، ثم ألغِ صلاحية القديم.
- يظهر بجوار كل مفتاح وقت آخر استخدام له.

## إشعارات الأحداث التلقائية — Webhooks

عنوان استقبال الإشعارات هو عنوان المنصة الذي يرسل إليه ريفرديسك التحديثات، مثل تأكيد حجز أو تغيّر الإتاحة.

يظهر مفتاح توقيع الإشعارات مرة واحدة فقط عند إنشائه.

يعرض سجل الإرسال جميع الرسائل وحالاتها: تم التسليم، أو قيد الانتظار، أو فشل. ويمكن استخدام «إعادة الإرسال» لإرسال رسالة مجددًا.
