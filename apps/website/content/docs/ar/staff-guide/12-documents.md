# المستندات

من قسم «المستندات» في صفحة الحجز، اختر اللغة («العربية» أو «English» أو «الاثنتان»)، ثم المستند المطلوب. يُجهَّز خلال ثوانٍ ويُنزَّل بصيغة PDF.

| المستند                              | المحتوى                                                                                                                                                                                                                                                      |
| ------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| قسيمة الحجز                          | رقم الحجز ومرجعه لدى الشركة، والمركب، وبرنامج الرحلة، وتواريخ وموانئ ومواعيد الصعود والنزول، والكبائن والضيوف، وما يشمله السعر وما لا يشمله، وتعليمات الصعود، ورقم الطوارئ، والإجماليات، والبرنامج اليومي. وتُضاف متطلبات إثبات الهوية للأسعار التي تشترطها. |
| قسيمة الحجز — نسخة الشركة بدون أسعار | بيانات القسيمة نفسها دون الأسعار، لتسلّمها الشركة إلى ضيفها.                                                                                                                                                                                                 |
| برنامج الرحلة                        | التواريخ وموانئ التوقّف يومًا بيوم.                                                                                                                                                                                                                          |
| جدول الدفع                           | الإجمالي والمسدّد والمتبقي، ومواعيد استحقاق الدفعة المقدّمة والمبلغ المتبقي، والمدفوعات المستلمة.                                                                                                                                                            |
| شروط الإلغاء                         | نسب رسوم الإلغاء بحسب المدة المتبقية قبل الصعود، وفق السياسة الأصلية للحجز.                                                                                                                                                                                  |

يطبع خيار «الاثنتان» كل عنوان وتسمية بالعربية وتحتها الإنجليزية، مع كتابة التواريخ والأرقام بالأرقام اللاتينية، ليناسب الموظفين والضيوف بأي من اللغتين.

يحمل كل مستند شعارك وألوانك وبيانات التواصل من «الإعدادات ← الهوية البصرية». ويُؤخذ رقم الطوارئ وملاحظات القسيمة من «الإعدادات» أيضًا. استكمل هذه البيانات قبل إصدار أول قسيمة.

تُحفظ المستندات لمدة أسبوع ثم تُحذف، ويمكن إنشاؤها مجددًا في أي وقت.
