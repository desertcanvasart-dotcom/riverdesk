# الضيوف وكشوف الركاب

## اختيار الرحلة

تعرض قائمة الرحلات المواعيد خلال الفترة المحدّدة، مع عدد الكبائن المحجوزة وعدد الحجوزات التي لم تحصل على رقم كابينة بعد.

اختر رحلة لعرض جميع الضيوف الموجودين على متنها، بما يشمل من بدأت برامجهم قبلها أو تنتهي بعدها.

![الضيوف وكشوف الركاب](/screens/{locale}/desktop-guests.jpg 'ضيوف رحلة وكبائنهم، مع خيارات التصدير.')

## تخصيص أرقام الكبائن

يحجز النظام فئة الكابينة أولًا، مثل «قياسية»، ويُحدَّد الرقم الفعلي لاحقًا، مثل 101.

يمكن التخصيص بطريقتين:

- **تلقائيًا:** ينفّذ النظام التخصيص ليلًا للرحلات التي دخلت الفترة المحدّدة، وهي ٧ أيام قبل الصعود افتراضيًا. ويحاول إبقاء كل مجموعة في الكابينة نفسها طوال برنامجها. ويمكن تنفيذ التخصيص فورًا للرحلة المفتوحة باستخدام «تخصيص الكبائن الآن».
- **يدويًا:** اختر «تغيير» بجوار المجموعة لعرض الكبائن المتاحة طوال مدة إقامتها، ثم اختر كابينة أو ألغِ التخصيص.

يرفض النظام تخصيص الكابينة نفسها لمجموعتين على الرحلة نفسها.

## خريطة الكبائن

بدّل العرض من «القائمة» إلى «خريطة الكبائن» لعرض الأسطح وكبائنها بترتيب الأرقام، مع فئة كل كابينة.

| اللون              | المعنى                                                                                                 |
| ------------------ | ------------------------------------------------------------------------------------------------------ |
| أبيض               | كابينة متاحة.                                                                                          |
| أزرق مخضر          | كابينة بها ضيوف، مع اسم الضيف الرئيسي وعدد الضيوف وما إذا كانوا قد صعدوا قبل الرحلة أو سيستمرون بعدها. |
| أحمر               | كابينة موقوفة؛ ويمكن تمرير المؤشر لمعرفة السبب.                                                        |
| رمادي بإطار متقطّع | كابينة خارج الخدمة في التاريخ المحدّد.                                                                 |

تظهر أعلى الأسطح أعداد الكبائن المتاحة والمحجوزة مؤقتًا والمحجوزة لكل فئة.

تمثّل الحجوزات المؤقتة وحصص الشركات أعدادًا داخل الفئة، ولا تُربط بكبائن فعلية على الخريطة قبل تحويلها إلى حجوزات وتخصيصها.

![خريطة الكبائن](/screens/{locale}/guide-cabin-map.jpg 'خريطة الكبائن بحسب الأسطح.')

### نقل مجموعة إلى كابينة أخرى — للمالكين وموظفي الحجوزات

1. اضغط على كابينة بها ضيوف، أو اختر مجموعة من الصندوق الأصفر للمجموعات المنتظرة.
2. تُميَّز بالأخضر الكبائن المناسبة والمتاحة طوال ليالي برنامج المجموعة، مع عرض عددها.
3. اختر كابينة لنقل المجموعة إليها طوال إقامتها.

يُلغي «إخراجها من هذه الكابينة» التخصيص، وتعود المجموعة إلى الانتظار حتى تخصيصها مجددًا.

يبقى البيع بحسب فئة الكابينة، بينما تحدّد الخريطة مكان إقامة كل مجموعة.

## تصدير الكشوف

| المستند                          | المحتوى                                                                                 | الصلاحيات                                                         |
| -------------------------------- | --------------------------------------------------------------------------------------- | ----------------------------------------------------------------- |
| كشف الركاب — PDF أو Excel        | كل ضيف مع الكابينة والفئة والجنسية وتاريخ الميلاد ورقم جواز السفر والحجز وبرنامج الرحلة | المالكون وموظفو الحجوزات. يُوثَّق كل تنزيل، ويُحذف الملف بعد يوم. |
| كشف توزيع الكبائن — PDF أو Excel | كل كابينة مع ضيوفها وأعداد البالغين والأطفال والحجز والشركة، دون أرقام جوازات السفر     | المالكون وموظفو الحجوزات والمالية.                                |

اختر اللغة بجوار أزرار التصدير. يُنزَّل الملف بعد تجهيزه، وعادةً خلال ثوانٍ.
