# لوحة التشغيل التجريبي

يرى الملاك **التشغيل التجريبي** في القائمة. وهي تجيب عن سؤال واحد: هل من الآمن الاستمرار في التشغيل؟

| البطاقة                   | كيف تبدو الحالة السليمة                                                                                                                                 |
| ------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **فحص الثوابت**           | _كل الثوابت سليمة_: أعداد الكبائن والحجوزات المؤقتة والحجوزات متطابقة في كل مكان                                                                        |
| **البيع الزائد**          | _لا يوجد بيع زائد_. الكابينة التي أُخرجت في حالة طوارئ وهي محجوزة تظهر بشكل منفصل: البيع هناك متوقف بالفعل                                              |
| **سرعة الرد على الطلبات** | الطلبات المستلمة والتي تم الرد عليها في آخر ٣٠ يومًا، وعدد ما ينتظر الرد أو انتهت مهلته، وسرعة ردك (الوسيط، والمدة التي يُرد خلالها على ٩٠٪ من الطلبات) |
| **الاستثناءات المفتوحة**  | قليلة، وليست قديمة                                                                                                                                      |
| **الحجوزات حسب القناة**   | الحجوزات، والمؤكدة، والملغاة، والطلبات المفتوحة لكل قناة في آخر ٣٠ يومًا                                                                                |

إذا أظهر فحص الثوابت أي مشكلة، يكون البيع قد توقف بالفعل حيث حدثت. تواصل مع فريق ريفرديسك.
