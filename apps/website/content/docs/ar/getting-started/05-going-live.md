# بدء التشغيل الفعلي

## ١. استيراد حجوزاتك المستقبلية الحالية

تُستورد الحجوزات الموجودة لديك من جدول بيانات محفوظ بصيغة CSV. استخدم القالب `docs/pilot/import-template.csv` الموجود في مستودع «ريفرديسك»؛ وسيرسله إليك فريق «ريفرديسك».

**صف واحد لكل كابينة.** الصفوف التي تتبع حجزًا واحدًا تحمل نفس قيمة `external_ref` (رقم حجزك الحالي).

| العمود                                  | المعنى                                                    | مثال                      |
| --------------------------------------- | --------------------------------------------------------- | ------------------------- |
| `external_ref`                          | رقم حجزك                                                  | `OLD-1002`                |
| `channel_code`                          | فارغ للحجز المباشر، أو رمز الوكالة                        | `nilecrz`                 |
| `vessel_code`، `itinerary`              | كما يظهران في شاشة الجدول                                 | `NILEDEMO`، `LXR-7`       |
| `embark_date`                           | السنة-الشهر-اليوم                                         | `2026-12-07`              |
| `market`                                | `international` أو `egyptian_resident`                    | `international`           |
| `category_code`، `adults`، `child_ages` | فئة الكابينة، وعدد البالغين، وأعمار الأطفال مفصولة بـ `;` | `SUP`، `2`، `4;8`         |
| `guests`                                | أسماء الضيوف في هذه الكابينة مفصولة بـ `\|`               | `Lukas Weber\|Anna Weber` |
| `nationality`                           | حرفان                                                     | `DE`                      |
| `expected_total`                        | الإجمالي المتفق عليه، للمقارنة مع أسعار اليوم             | `4876.00`                 |
| `paid_amount`، `paid_reference`         | المبلغ المستلم بالفعل، ويُسجَّل كدفعة واحدة               | `1200.00`، `TT 7781`      |

كيف يعمل الاستيراد:

- يُنشأ كل حجز تمامًا مثل الحجز في المكتب، لذلك يشغل كبائن حقيقية.
- **تجربة دون حجز** تأتي أولًا: تحسب أسعار كل شيء ولا تحجز شيئًا، وتعرض ما سيحدث.
- المشكلات **يُبلَّغ عنها، ولا تُفرض أبدًا**: تاريخ بلا إبحار، أو فئة غير معروفة، أو عدم وجود أماكن متبقية. تصلحها أنت يدويًا.
- إذا اختلف الإجمالي المتفق عليه عن أسعار اليوم، يُنشأ الحجز بأسعار اليوم ويُبلَّغ عن الفرق، حتى تتمكن من تعديله.
- تشغيل نفس الملف مرة أخرى آمن: الحجوزات المستوردة من قبل يتم تخطيها.

## ٢. قائمة المراجعة قبل التشغيل الفعلي

قبل أول حجز حقيقي، يراجع فريق «ريفرديسك» هذه القائمة معك:

- **كلمات المرور والمفاتيح** التي استُخدمت أثناء الإعداد تم تغييرها.
- **تسجيل الدخول بخطوتين** مُفعَّل لكل مالك وكل موظف مالية.
- **الأشخاص والأدوار** تمت مراجعتهم: لا حسابات مشتركة.
- **النسخ الاحتياطية** تم التحقق منها، بما في ذلك الاستعادة إلى دقيقة محددة («الاستعادة إلى لحظة محددة»).
- **التنبيهات** تصل إلى المكتب عندما يحتاج أمر ما إلى انتباه.
- **حزمة الطوارئ الليلية** تصل إلى بريد العمليات لديك.
- **المستندات** تُطبع بشكل صحيح بالعربية والإنجليزية.
- **المنصات الإلكترونية** (مثل nilecrz) اختبرت اتصالها على شركة تجريبية.
- **الاستيراد** تمت مراجعته مع مدير الحجوزات لديك.
- **الموظفون** قام كل منهم بتسجيل حجز هاتفي، والرد على طلب، وتسجيل دفعة، وطباعة قسيمة حجز.
- **لوحة التشغيل التجريبي** تُظهر نجاح كل الفحوصات وعدم وجود بيع زائد.
