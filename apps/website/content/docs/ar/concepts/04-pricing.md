# التسعير

## خطط الأسعار والمواسم

**خطة الأسعار** قائمة أسعار لـ**سوق** واحدة وعملة واحدة، مثل _دولي، دولار أمريكي_ أو _دول الخليج، ريال سعودي_. والأسواق قائمتك الخاصة (الإعدادات ← الأسواق). و**المواسم** فترات زمنية (مرتفع، منخفض، الأعياد). ويُسعَّر الإبحار حسب موسم تاريخ الصعود، لكل لياليه.

تسعّر الخطة بإحدى الطرق التالية:

- **للفرد** (حسب الإشغال: فردي، مزدوج، ثلاثي) أو **للكابينة**؛
- **لليلة** أو **للرحلة كاملة** (خط السير بأكمله).

## مثال عملي

بالغان وطفل عمره ٧ سنوات في كابينة Standard، على LXR-4، بخطة للفرد وللرحلة كاملة، والسعر المزدوج ٥٨٥ دولارًا أمريكيًا:

| البند                           | المبلغ       |
| ------------------------------- | ------------ |
| بالغ (مزدوج)                    | ٥٨٥٫٠٠       |
| بالغ (مزدوج)                    | ٥٨٥٫٠٠       |
| طفل ٧ سنوات (٥٠٪ من سعر البالغ) | ٢٩٢٫٥٠       |
| **الإجمالي**                    | **١٬٤٦٢٫٥٠** |

يُقرَّب كل بند وحده، لذلك يساوي الإجمالي دائمًا مجموع بنوده. وتُحفظ المبالغ بالسنتات الكاملة، ولا تُحفظ أبدًا بكسور عشرية.

## الأطفال

تحدد سياسة الأطفال فئات عمرية، مثلًا:

| العمر في تاريخ الصعود | السعر                                           |
| --------------------- | ----------------------------------------------- |
| ٠–١                   | مجانًا                                          |
| ٢–٥                   | ٢٥٪ من سعر البالغ، عند المشاركة مع بالغين اثنين |
| ٦–١١                  | ٥٠٪ من سعر البالغ، عند المشاركة مع بالغين اثنين |
| ١٢ فأكثر              | بالغ                                            |

الطفل الذي لا يشارك الكابينة مع بالغين اثنين يُسعَّر كبالغ. وإذا أُدخل تاريخ الميلاد لاحقًا وأظهر فئة عمرية مختلفة، يُعلَّم الحجز في صفحة اليوم، ولا يُعاد تسعيره.

## المبالغ الإضافية

رسوم إضافية في تواريخ معينة، مثل عشاء الحفل، لكل بالغ ولكل طفل.

## القنوات

قد يضيف عقد القناة **زيادة** (فيكون سعر القناة أعلى)، أو يعرض **عمولة** (معلومة للقناة، لا تُضاف إلى الإجمالي).

## الأسعار تُثبَّت لحظة البيع

يحتفظ الحجز بالأسعار والسياسات السارية لحظة بيعه. وتغيير الأسعار لاحقًا يؤثر في عروض الأسعار الجديدة فقط.
