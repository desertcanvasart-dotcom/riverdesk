# الحجوزات المؤقتة والطلبات وحالات الحجز

## الحجوزات المؤقتة

يحتفظ الحجز المؤقت بالكبائن لمدة محدّدة قبل تأكيد الحجز، بحسب الغرض منه.

| النوع                       | الاستخدام                                                   | المدة الافتراضية |
| --------------------------- | ----------------------------------------------------------- | ---------------- |
| مهلة إتمام الدفع الإلكتروني | الاحتفاظ بالكبائن أثناء دفع الضيف على موقع إحدى قنوات البيع | ٣٠ دقيقة         |
| الحجز المؤقت للشركة         | منح الشركة مهلة لتأكيد اختيارها                             | ٧٢ ساعة          |
| العرض البديل                | الاحتفاظ بكبائن موعد بديل مقترح ردًا على طلب حجز            | ٤٨ ساعة          |
| انتظار الدفعة المقدّمة      | الاحتفاظ بكبائن الحجز المباشر إلى حين سداد الدفعة المطلوبة  | ٢٤ ساعة          |

تنتهي الحجوزات المؤقتة تلقائيًا عند انقضاء مهلتها. وتفحص خدمة المهام التلقائية الحجوزات المنتهية كل دقيقة لتحرير الكبائن، دون الحاجة إلى متابعة يدوية.

## حالات الحجز

| الحالة                       | معناها                                                   | متى تظهر؟                                                         |
| ---------------------------- | -------------------------------------------------------- | ----------------------------------------------------------------- |
| طلب حجز                      | أرسلت الشركة طلبًا، ولم تُحجز كبائن بعد                  | عند العمل بعقد «الحجز عند الطلب»، أو عند تجاوز الشركة حد الائتمان |
| تم عرض بديل                  | اقترح المكتب موعد إبحار آخر                              | عند الرد على طلب بعرض بديل                                        |
| بانتظار الدفع                | الكبائن محفوظة مؤقتًا إلى حين استلام الدفعة المقدّمة     | في الحجز المباشر الذي يشترط الدفع المسبق                          |
| مؤكّد                        | أصبحت الكبائن مرتبطة بحجز مؤكّد                          | بعد التأكيد، أو قبول الطلب، أو تسجيل الدفعة المقدّمة المطلوبة     |
| تم الدفع والكابينة غير متاحة | وصلت دفعة بعد انتهاء الحجز المؤقت، وكانت الكبائن قد بيعت | عند وصول دفعة متأخرة تحتاج إلى قرار من المكتب                     |
| مرفوض                        | رفض المكتب طلب الحجز                                     | بعد رفض الطلب                                                     |
| منتهٍ                        | انتهت مهلة الطلب دون رد                                  | عند انقضاء الوقت المتاح للرد                                      |
| ملغى                         | أُلغي الحجز، مع تطبيق الرسوم وفق سياسته                  | بعد الإلغاء بواسطة الموظفين أو قناة البيع                         |
| مكتمل                        | انتهى برنامج الرحلة                                      | تلقائيًا بعد الليلة الأخيرة                                       |

## نسخ الحجز وسجل التعديلات

ينشئ كل تعديل معتمد على التاريخ أو الكبائن أو أعداد النزلاء نسخة جديدة من الحجز، تتضمن السعر والرسوم المرتبطة بالتعديل.

تبقى النسخ السابقة محفوظة في سجل التعديلات، ولا تُستبدل أو تُمحى.

وتحتفظ كل نسخة أيضًا بالسياسات التي استند إليها الحجز.
