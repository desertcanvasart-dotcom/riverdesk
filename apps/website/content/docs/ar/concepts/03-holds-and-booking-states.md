# الحجوزات المؤقتة والطلبات وحالات الحجز

## الحجوزات المؤقتة

**الحجز المؤقت** يحجز الكبائن لوقت قصير قبل تأكيد الحجز:

| النوع  | لمن                            | المدة الافتراضية |
| ------ | ------------------------------ | ---------------- |
| الدفع  | ضيف يدفع على موقع إحدى القنوات | ٣٠ دقيقة         |
| الخيار | خيار لوكالة                    | ٧٢ ساعة          |
| العرض  | تاريخ بديل يُعرض ردًا على طلب  | ٤٨ ساعة          |
| الدفعة | حجز مباشر ينتظر العربون        | ٢٤ ساعة          |

تنتهي الحجوزات المؤقتة **تلقائيًا** في الوقت المحدد بالضبط: يحررها البرنامج الخلفي (worker) كل دقيقة، ولا يعتمد شيء على أن يتذكر أحد.

## حالات الحجز

| الحالة                        | المعنى                                                  | مصدرها                                     |
| ----------------------------- | ------------------------------------------------------- | ------------------------------------------ |
| **طلب**                       | طلبت وكالة، ولم تُؤخذ أي كبائن بعد                      | عقد عند الطلب، أو وكالة تجاوزت حد الائتمان |
| **تم عرض بديل**               | اقترحتَ إبحارًا آخر                                     | طلب                                        |
| **بانتظار الدفع** (حجز مؤقت)  | الكبائن محجوزة مؤقتًا حتى يصل العربون                   | حجز مباشر (مدفوع مسبقًا)                   |
| **مؤكد**                      | الكبائن محجوزة                                          | تأكيد، أو قبول طلب، أو دفع العربون         |
| **مدفوع والكابينة غير متاحة** | وصل المال بعد انتهاء الحجز المؤقت وكانت الكبائن قد بيعت | دفعة متأخرة تحتاج إلى قرار                 |
| **مرفوض**، **منتهي**          | طلب رُفض أو لم يُرد عليه في الوقت المحدد                | طلب                                        |
| **ملغي**                      | أُلغي، مع الغرامة المحددة في سياسته                     | الموظفون أو إحدى القنوات                   |
| **مكتمل**                     | انتهت الرحلة                                            | تلقائيًا، بعد الليلة الأخيرة               |

## المراجعات

كل تغيير مؤكد (التاريخ، أو الكبائن، أو إشغال الضيوف) ينشئ **مراجعة** جديدة بسعرها ورسومها. لا يُمحى السجل السابق أبدًا. وتحتفظ كل مراجعة أيضًا بنسخة من السياسات التي بيع الحجز بموجبها.
