# القنوات والعقود

**القناة** هي أي جهة تبيع كبائنك:

| النوع        | مثال                                        |
| ------------ | ------------------------------------------- |
| المكتب       | مكتبك أنت: الهاتف، واتساب، الزيارة المباشرة |
| وكيل         | وكالة سفر                                   |
| بوابة        | منصة إلكترونية مثل nilecrz                  |
| واجهة برمجية | نظام آخر يتصل مباشرة                        |

لكل قناة **عقد** لكل مركب يحدد:

- **الفئات وخطط الأسعار** التي يجوز لها بيعها؛
- **تخصيصها**: المخزون المشترك، أو تخصيص خاص بها، أو عند الطلب؛
- **طريقة الدفع** (راجع [المدفوعات](/docs/concepts/payments))؛
- **الزيادة أو العمولة**؛
- **مدد الحجز المؤقت**، و**مهلة الرد** في حالة البيع عند الطلب؛
- **حد العرض** الاختياري، وهو أقصى عدد من الكبائن المتاحة يُعرض عليها في وقت واحد؛
- **إيقاف البيع**، الذي يوقف تلك القناة وحدها.

يُطبَّق العقد على كل عملية، في المكتب وعبر الواجهة البرمجية على حد سواء. ولا ترى أي قناة حجوزات قناة أخرى أو حجوزاتها المؤقتة، ولا تتعامل معها أبدًا.
