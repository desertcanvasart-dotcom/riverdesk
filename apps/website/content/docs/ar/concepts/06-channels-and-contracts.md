# قنوات البيع والعقود

## ما هي قناة البيع؟

قناة البيع هي أي جهة تبيع كبائنك.

| النوع          | المثال                                                                |
| -------------- | --------------------------------------------------------------------- |
| المكتب         | الحجوزات التي يستقبلها مكتبك عبر الهاتف أو واتساب أو الزيارة المباشرة |
| شركة           | شركة تحجز رحلاتك لعملائها                                             |
| منصة إلكترونية | منصة مثل nilecrz                                                      |
| واجهة برمجية   | نظام آخر يتصل مباشرة بريفرديسك                                        |

## ما الذي يحدّده العقد؟

لكل قناة بيع عقد مستقل لكل مركب، يحدّد:

- فئات الكبائن وخطط الأسعار المسموح ببيعها.
- طريقة إتاحة الكبائن: مخزون مشترك، أو حصة مخصّصة للشركة، أو حجز عند الطلب.
- طريقة الدفع والتحصيل.
- نسبة الزيادة أو العمولة.
- مدد الحجوزات المؤقتة.
- مهلة الرد على الطلبات، عند استخدام الحجز عند الطلب.
- حد الإتاحة المعروض، وهو عدد اختياري يقيّد أقصى عدد من الكبائن المتاحة التي تراها القناة في المرة الواحدة.
- إيقاف البيع للقناة عند الحاجة، دون التأثير على غيرها.

لشرح طرق التحصيل، راجع [المدفوعات والدفعات المقدّمة والمبالغ المستردة](/docs/concepts/payments).

## تطبيق شروط العقد

تُطبَّق شروط العقد على كل عملية، سواء نفّذها فريقك من المكتب نيابةً عن الشركة أو أرسلها نظام الشركة عبر واجهة برمجة التطبيقات.

ولا تستطيع أي قناة الاطّلاع على الحجوزات أو الحجوزات المؤقتة التابعة لقناة أخرى، أو إجراء عمليات عليها.
